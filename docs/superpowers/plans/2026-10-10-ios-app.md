# iOS 版跳绳计数器 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `ios/` 下交付与 Android 版功能一致的 SwiftUI 跳绳计数应用，核心算法与 Android 逐帧对齐。

**Architecture:** 纯 Swift 包 `RopeCore`（检测器、训练引擎、模型、CSV）在 macOS 上用 `swift test` 验证；SwiftUI 应用 `RopeCounter` 通过 xcodegen 生成工程，链接提交到仓库的 MediaPipe xcframework，模型复用 Android 的 `pose_landmarker_lite.task`。

**Tech Stack:** Swift 5.9+/SwiftUI/AVFoundation/AVFAudio, MediaPipeTasksVision 1.0.0 (xcframework), xcodegen 2.x, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-10-ios-app-design.md`

## Global Constraints

- Bundle ID `com.yzrun.ropecounter`，最低 iOS 17，仅竖屏。
- 所有用户可见文案与 Android 版相同（中文）。
- 检测器与引擎的数值、阈值、状态流转必须与 Kotlin 版一致；Kotlin 源在 `app/src/main/java/com/yzrun/ropecounter/`。
- 不引入任何需要网络拉取的依赖。
- 每个任务结束 `swift test` 或 `xcodebuild build` 必须通过后再提交。

## Review Focus

1. 回放 CSV 中某帧关键点全为 0（模型未检出）→ 检测器返回「请保持全身入镜」且不崩溃。测试加在 Task 2。
2. 校准窗口内已有一跳 → 校准完成那一帧 `jumpCount` ≥ 1。测试加在 Task 2（移植用例已覆盖）。
3. 定时模式暂停 25 s 后恢复 → 暂停时间不计入本组。测试加在 Task 3（移植用例已覆盖）。
4. 用户录音文件存在但损坏 → `AVAudioPlayer` 初始化失败时回退到内置音频，不崩溃。Task 7 手动验证。
5. 摄像头权限被拒 → 训练界面显示提示而非黑屏。Task 8 手动验证。
